# bolens Profile Constitution

[Documentation](../../docs/README.md)

## Core Principles

### I. Accurate Public Identity
Claims about projects, skills, activity, and availability MUST be current, supportable, and phrased without inflated or unverifiable metrics.

### II. Concise, Accessible Presentation
The profile MUST remain readable in GitHub's rendered Markdown, use meaningful link text and image alternatives, and prioritize maintained work over decoration.

### III. Privacy and Secret Safety
Private contact details, credentials, internal infrastructure, and sensitive activity MUST NOT be published. External badges and embeds MUST be intentional and trustworthy.

### IV. Verified Links and Attribution
Project links, social links, badges, and credits MUST resolve to the intended destinations. Third-party assets and copied material MUST retain required attribution.

## Governance

The rendered profile is the product. Changes require previewing the Markdown and checking links. Amendments require rationale and a version update.
