# Hi, I'm Michael 👋

I build practical tools for Linux desktops, self-hosted infrastructure, and the
small annoyances between them.

Most of my work lives close to the system: dynamic DNS, shell environments,
game-launch pipelines, desktop automation, and incident-response utilities. I
care about tools that are easy to inspect, safe to run, and pleasant to use.

📍 Lakewood, Colorado · formerly Milwaukee, Wisconsin

## What I'm working on

- Building **[uDDNS](https://github.com/bolens/uddns)**, a small multi-provider
  dynamic DNS updater in TypeScript
- Developing **[aur-response-toolkit](https://github.com/bolens/aur-response-toolkit)**,
  Rust-based incident-response tooling for Arch Linux supply-chain threats
- Improving Linux gaming and desktop workflows across Steam, Gamescope,
  Proton, KDE Plasma, Hyprland, Waybar, and Rofi
- Running a Docker Compose homelab with Caddy, secure remote access,
  monitoring, and automation
