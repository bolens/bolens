# Development environments

Provide locked tools for the public profile repository's Markdown, shell, JSON, and workflow checks, plus a source-free development image and Docker/Podman/Apple adapters. Reuse the shared fleet Markdown rules and the existing pre-push checks. Preserve README identity, assets, and public claims.

Acceptance: native and container commands report lint/test failures, preserve arguments and caller ownership, and do not publish images or profile changes. Record rendered review and external link verification separately from source checks.
